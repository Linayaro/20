# מערכת חכמה לבקרת כניסה לקלפי - מעבדה 15, קבוצה 20

## שלב 1: הפעלה ואתחול המערכת
1. חברו את לוח ה-Arduino UNO למחשב באמצעות כבל USB.
2. פתחו את תוכנת Arduino IDE ובחרו את הלוח והפורט המתאימים.
3. ודאו שמותקנות הספריות הבאות: Wire, LiquidCrystal_I2C, Servo, IRremote, VL53L1X.
4. טענו את הקוד לבקר ופתחו את ה-Serial Monitor בקצב תקשורת של 9600.
5. בצעו הגדרה ראשונית של השלט באמצעות שתי לחיצות קצרות על כל אחד מהכפתורים הבאים, לפי הסדר: OK, 1, 9.
6. המערכת תעבור למצב המתנה.

## שלב 2: תהליך כניסה תקין
1. אדם מתקרב לחיישן המרחק ונמצא בטווח של 2–30 ס"מ.
2. נורת ה-LED נדלקת ובמסך ה-LCD מופיעה בקשה לאישור כניסה.
3. המפעיל מאשר את הכניסה באמצעות לחיצה על OK בשלט.
4. מנוע הסרבו פותח את המחסום.
5. מד הלייזר מזהה את האדם באזור המעבר ואת פינוי האזור לאחר המעבר.
6. מונה הכניסות גדל באחת והמחסום נסגר אוטומטית.
7. המערכת חוזרת למצב המתנה לאחר פינוי אזור הכניסה.

## שלב 3: ביטולים ומצבים חריגים
- בהיעדר אישור כניסה במשך 10 שניות, בקשת הכניסה מתבטלת.
- בהיעדר מעבר במשך 20 שניות, וכאשר אזור המעבר פנוי לפי מדידת לייזר תקינה, המחסום נסגר ללא ספירת כניסה.
- לחיצה על הספרה 1 בשלט או על הכפתור הפיזי מאפשרת ביטול בקשת כניסה או סגירת המחסום כאשר אזור המעבר פנוי.
- לחיצה על הספרה 9 בשלט מאפשרת סגירה כפויה ואיפוס מחזור הפעולה, ללא איפוס מונה הכניסות. יש להפעיל פקודה זו רק כאשר המעבר פנוי.

## שלב 4: הפעלה בסימולטור Tinkercad
בסימולטור קיימים שני הבדלים עיקריים:
- כפתור Play/Pause בשלט מחליף את כפתור OK.
- כפתור המחובר לפין D2 מדמה את פעילות מד הלייזר. לחיצה מדמה נוכחות אדם במעבר ושחרור מדמה את פינויו.
כמו כן, בסימולטור קיימים מספר הבדלים ביחס למערכת הפיזית.

## שלב 5: סיום העבודה
יש לוודא שהמערכת נמצאת במצב מנוחה, לסגור את הצג הסריאלי ולנתק את מקור המתח.
